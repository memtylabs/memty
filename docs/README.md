# Memty user documentation

Memty keeps small facts in a local vault so you can reuse them with different AI tools. Start with the quick start, then choose the guide for how you want to use it.

| Guide | What you will learn |
| --- | --- |
| [Getting started](getting-started.md) | Install Memty and save your first fact |
| [Browser guide](browser.md) | Install the extension, save and paste contexts, and manage facts |
| [Coding agents and MCP](mcp.md) | Connect a client and use memory with an agent |
| [Memory and commands](memory-and-commands.md) | Manage facts, namespaces, proposals, receipts, and the CLI |
| [Privacy and security](privacy.md) | Understand sensitivity, provider settings, and data limits |
| [Python API](python-api.md) | Use Memty from your own Python code |
| [Troubleshooting and maintenance](troubleshooting.md) | Fix common problems, upgrade, back up, and uninstall |
| [Runnable examples](../examples/README.md) | Try Python examples with temporary demo vaults |

These guides describe the current repository, including changes planned for **0.2.2**, which is not yet published. In particular, bulk delete and the 0.2.2 summary privacy changes require that version or a checkout containing those changes. Check your installed version with `memty --version` and use `memty COMMAND --help` for the options it supports.

For security reports, see the [security policy](../SECURITY.md). For tests of Memty itself, see [security testing](SECURITY_TESTING.md). The [changelog](../memty/CHANGELOG.md) records release-specific changes.

Maintainers can also use the [release guide](RELEASING.md).
